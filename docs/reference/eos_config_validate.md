## eos config validate

Validate ~/.eos/config.yaml

### Synopsis

Validate ~/.eos/config.yaml without starting the daemon, reporting the same error the daemon would refuse to start on.

```
eos config validate [flags]
```

### Examples

```
  eos config validate
```
